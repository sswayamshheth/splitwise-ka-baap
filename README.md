# Settlr

![Settlr](docs/settlr-banner.jpg)

Group trips get messy. Someone drops out, a booking gets cancelled, it rains on the day you planned to go diving. Settlr keeps everyone's money right through all of it.

- **Plan together.** Build the itinerary as a group, or upload a PDF or photo and let AI turn it into a plan.
- **Pool and pay.** Collect everyone's share, pay vendors, and settle up in the fewest possible transfers.
- **Changes fix themselves.** When plans change, every balance updates, and you can see exactly why you owe what you owe.
- **Weather-aware.** If rain hits a booking, Settlr moves it to a better day first, and suggests alternatives only if it has to.
- **Tamper-proof.** Every change is sealed on Ethereum, so nobody can quietly rewrite who paid what.

## Run it

```bash
cd web
npm install
npm run dev
```
